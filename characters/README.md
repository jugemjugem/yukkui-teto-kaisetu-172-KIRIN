# characters

このフォルダは、YMM解説動画で使用するキャラクター設定を管理する場所です。

## ファイル一覧

- `teto.md`  
  解説役。SCPや財団について詳しい。たまに怪しい。

- `shizunon.md`  
  聞き手・ツッコミ役。視聴者目線で質問する。

- `kirin.md`  
  題材SCP。巨大でかわいい、観測しづらいきりんさん。

## 台本作成時の使い方

台本を書く前に、このフォルダのキャラクター設定を確認する。  
口調、役割、やりすぎ注意を守りながら、掛け合いを作る。

## 基本方針

- 怖くしすぎない
- SCPらしさは残す
- きりんさんは基本かわいい
- てとさんは詳しいが少し怪しい
- しずのんさんは視聴者目線で質問する
